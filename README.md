# bhmsuz — Ўзбекистон БҲМС (НСБУ) скилли учун Claude Code

`uz-bxms-nsbu` — Claude Code скилли: Ўзбекистон бухгалтерия ҳисоби миллий стандартлари (БҲМС / НСБУ) расмий матнларига қараб ҳужжат ва мақолаларни текширади. 1С:Бухгалтерия (Ўзбекистон) аудит мақолалари ёзилганда норматив даъволар (тан олиш мезони, амортизация, баҳолаш, счётлар) расмий банд рақами билан тасдиқланади; тасдиқланмаган жойлар `*` билан белгиланади.

## Ўрнатиш
```
git clone https://github.com/Debetuz/bhmsuz
```
`uz-bxms-nsbu` папкасини лойиҳангизнинг `.claude/skills/` ичига (ёки глобал `~/.claude/skills/` га) нусхаланг. Claude Code скиллни ўзи топади.

## Муҳим эслатмалар
- Матнлар lex.uz дан олинган расмий матнларнинг **иш учун қисқартирилган нусхалари**; баъзилари тўлиқ эмас (файл бошида «Ҳолат» сатрида кўрсатилган). Юридик маслаҳат эмас; расмий манба — lex.uz.
- Меъёрлар ўзгариши мумкин: БРВ қиймати ва бошқа чегаралар матнларда йўқ, жорий қиймат расмий манбадан аниқланади.
- Етишмайди: №3, №14, №15 (бекор қилинган), №18, №25 ва ундан кейинги стандартлар; №21 йўриқномасининг охири; баъзи стандартларнинг узилган қисмлари.
